# Environmental Emissions Analytics Dashboard

## Project Objective
To analyze environmental emissions data using SQL, Excel, and Power BI to identify emissions trends, major emission sources, unusual changes, and potential data-quality issues.

## Problem Statement
Organizations need reliable environmental data to monitor emissions, understand their environmental impact, and support sustainability reporting. However, emissions data may contain missing values, inconsistencies, and changes that require investigation. This project aims to organize, validate, and analyze emissions data through an interactive dashboard.

## Project Scope
- Analyze industrial greenhouse gas emissions.
- Examine emissions trends across reporting years.
- Compare emissions by industry, facility, location, and greenhouse gas where the data permits.
- Identify high-emitting facilities and significant changes in emissions.
- Perform data-quality checks for missing values, duplicates, inconsistent units, and unusual records.
- Present key performance indicators (KPIs) and findings through Power BI visualizations.

## Tools
- Excel: Data inspection and preliminary quality checks.
- SQL: Data validation, aggregation, and trend analysis.
- Power BI: Interactive dashboard and reporting.
- Python with pandas: Optional advanced data cleaning and analysis.

## Target Audience
Sustainability analysts, environmental reporting teams, ESG professionals, and environmental data analysts.

## Expected Deliverables
1. Documented environmental emissions dataset.
2. Data dictionary and quality-check log.
3. SQL analysis and validation queries.
4. Interactive Power BI dashboard.
5. Findings, limitations, and evidence-based recommendations.
6. GitHub repository containing project documentation and reproducible analysis.
